ResearchOS 隱私權政策

最後更新：2026 年 10 月 30 日

ResearchOS 是供個人研究及文獻管理使用的工具。本政策說明本工具在使用 Google OAuth 與 Google Drive 時，可能如何存取、使用、儲存與處理資料。此公開網站僅提供說明文件，不會要求訪客輸入 Google 登入資料或授權碼。

1. 需要的資料及權限

ResearchOS 使用 Google OAuth https://www.googleapis.com/auth/drive.file 權限，其目的僅在讀取使用者明確授權給應用程式的 Google Drive 文件及資料夾，並在使用者啟用寫入流程時建立衍生文件或索引。此權限不等於可任意存取使用者整個 Google Drive。

2. 資料使用目的

  • 取得經使用者授權的 PDF、文字檔或網頁文獻，以執行文字擷取、內容索引及品質檢查。
  • 記錄原始檔名稱、Drive 識別碼、來源網址、檔案雜湊值，以及處理報告，供研究來源追溯與錯誤排查。
  • 在使用者明確啟用後，於指定的 Google Drive 資料夾建立處理後的文字、索引及稽核報告。

3. 儲存位置與保存期間

原始研究文件保留於使用者管理的 Google Drive。經授權處理的輸出可能保存於使用者指定的 Google Drive 資料夾，或存放於私人 GitHub Actions 執行產物及紀錄中；現行部分工作流程將執行產物保留 14 天，其他使用者管理的 Drive 檔案將持續保留至使用者自行刪除。系統憑證應透過 GitHub Actions 加密 Secrets 或使用者本機安全設定保存，不會放入公開網站。

4. 與第三方服務的關係

本工具使用 Google Drive 作為使用者授權的檔案來源／目的地，並使用 GitHub Actions 執行部分自動化工作。資料可能在這些服務的正常運作範圍內被處理。本工具不以廣告定向、資料販售或行銷目的使用 Google 使用者資料；若未來新增其他雲端 AI 服務處理個人資料，應先更新相關揭露並取得適當授權。

5. 資料安全及使用限制

ResearchOS 的自動化流程以來源資料夾白名單及最小必要權限為原則，保留原始文件並避免自動刪除或覆寫。研究文字可能包含機器擷取誤差；任何引文與事實主張皆需另行核證。

6. 撤銷授權及刪除

使用者可在 Google 帳戶的第三方連線管理頁面 撤銷 ResearchOS 的 OAuth 存取權。撤銷授權後應停止新的 Google Drive API 存取，但不會自動刪除先前建立於 Google Drive、GitHub 執行紀錄或本機的檔案；這些資料須依其所在平台另行刪除。也可以刪除 Google Drive 的原始及衍生研究檔案。

7. 聯絡與政策變更

有關 ResearchOS 或個人資料使用的問題，請使用 Google OAuth 同意畫面列出的使用者支援信箱聯繫。一般性的公開網站問題可透過 GitHub Issues 回報；請勿在公開議題中張貼帳密、Token、私人文件或敏感資料。政策若隨資料處理方式變更，將同步更新此頁。
